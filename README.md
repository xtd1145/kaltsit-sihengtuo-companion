## 简介

她可以常驻桌面，陪你摸鱼、陪你专注。支持**点击、双击和长按互动**，也可以**拖动**她到屏幕的任意位置；点击或右键即可呼出快捷菜单。

- 🖱️ 点击 / 双击 / 长按触发随机互动动作，拖动时也有对应动作和落点反馈
- ☀️☁️🌙 **安静 / 日常 / 办公** 三种模式一键切换，不同模式下她会做不同的事情
- 🎞️ 内置**统一的 GIF 素材库**：自带大量动作与表情
- 📦 支持**导入自己的素材**、修改动作名称与互动文字，自由组合每种模式使用的动作
- 💬 互动文字气泡、大小调节、总在最前、开机自启
- 🎯 **鼠标穿透**：开启后桌宠不再拦截鼠标，点击会穿透到背后的窗口（可在托盘菜单或设置中关闭）
- 💬 **AI 聊天**：支持任意 OpenAI 兼容接口，聊天窗口 / 桌宠气泡双形态，可切换多种 Agent 人格
- 🧠 **知识库学习（RAG）**：粘贴或导入文档自动切块入库，对话时检索引用；内置离线中文向量小模型，也可用云端 Embedding
- 🔄 **自动更新**：从 GitHub Releases 自动发现新版本，一键静默升级（升级会保留本地 AI 接口与人格等设置）

目前已制作 **macOS** 与 **Windows** 两个版本。

## AI 聊天 💬

- 在「设置 → AI 聊天」填写 **Base URL / API Key / 模型** 即可对话（DeepSeek、OpenAI、通义、智谱、OpenRouter 等任何 OpenAI 兼容服务）
- **聊天窗口**：托盘或右键菜单「AI 聊天…」打开，流式回复、可停止、新对话
- **桌宠气泡**：把鼠标移到桌宠身上，底部输入条 Enter 发送，凯尔希用头顶气泡回话（对话方式可选：窗口 / 气泡 / 两者）
- **Agent 人格系统**：预置「凯尔希·思衡托」完整角色设定；可随时**新建 / 编辑 / 切换多个人格**（名称 + 系统提示词），切换即开新会话

## 知识库学习 🧠

让凯尔希学会你的资料，问它即答：

- **导入**：粘贴文本或导入文件（.txt / .md / .json / .csv / .srt），自动切块入库（支持多文档管理）
- **三种索引方式**，按需自选：
  - 关键词 —— 无需任何模型，任何电脑都能用
  - **内置模型** —— 程序自带 bge-small-zh 中文向量小模型（约 24MB），完全离线、零配置的语义检索（推荐）
  - 云端向量 —— 本机 Ollama / LM Studio 部署 Qwen 等小模型，或任意云端 Embedding API（性能不足的用户可直接用云 API）
- 对话时自动检索最相关的 1–8 条资料随问题发送给 AI 参考，回答有据可依

## 快速开始

```bash
npm install
npm start        # 本地运行
```

Windows 打包（产出 NSIS 安装包 `Setup-*.exe`）：

```bash
npm run dist
```

macOS 打包：

```bash
npm run dist:mac
```

> 发布新版本：为仓库打上 `vX.Y.Z` 格式的 tag，并在 GitHub Release 中附上安装包（文件名含 `Setup` 的 `.exe`）资产，桌宠即可在「设置 → 更新」中填写 `owner/repo` 后自动检查更新。

## 素材与动作

- 素材库位于 `character/assets`，动作定义见 `character/actions.json` 与 `character/character.json`。
- 在「动作管理」窗口中可直接导入 GIF、重命名、编辑互动台词，并按模式（安静/日常/办公）组合动作。
